Which model gives the best balance?

The study does not reward “accuracy” alone. A useful detector should find attacks while keeping false alarms under control.

RECOMMENDED MODEL

Logistic Regression

In the measured primary experiment, Logistic Regression provided the highest attack detection while satisfying the false-alarm constraint.

50.2% detection • 9.5% false alarms
Selection rule: Best attack detection among models satisfying FPR ≤ 10%.

WHY TEST ON LATER TRAFFIC?

Traffic changes. The test should too.

Instead of only shuffling the same data, the temporal split trains on earlier periods and checks whether the detector still works on later traffic.

Research question → answer

Q

Which model wins?

A

Logistic Regression: it achieves the highest attack detection (50.2%) while keeping false alarms at 9.5% (under the 10% cap) on verified reproduction runs.

Q

Why cap false alarms?

A

Because high recall is not useful if benign traffic is constantly flagged.

Q

Why temporal testing?

A

It checks whether the detector still works when later traffic patterns change.

Q

Why synthetic data?

A

The same declared seed recreates the same study, keeping it reproducible and auditable.
