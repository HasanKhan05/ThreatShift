WHY TEST ON LATER TRAFFIC?

Traffic changes. The test should too.

Instead of only shuffling the same data, the temporal split trains on earlier periods and checks whether the detector still works on later traffic.

Research question → answer

Q

Which model wins?

A

Random Forest in the current saved-evidence example.

Q

Why cap false alarms?

A

Because high recall is not useful if benign traffic is constantly flagged.

Q

Why temporal testing?

A

It checks whether the detector still works when later traffic patterns change.

Q

Why synthetic data?

A

The same declared seed recreates the same study, keeping it reproducible and auditable.
